# Program 7 — Heart Disease Classification

Dataset: `heart_disease.csv` in this folder.
The manual uses the last column as the target and all earlier columns as features.
The five values entered for a new patient must match the dataset's feature columns and order.

Note: The manual describes this as a Bayesian Network but its supplied implementation uses
GaussianNB (Gaussian Naive Bayes), which is a Naive Bayes classifier rather than a full Bayesian network.

Install: `python -m pip install pandas scikit-learn`
